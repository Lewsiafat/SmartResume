## 主版（zh-TW · 給 LinkedIn 首發）

履歷不再只是給人看的 PDF。
是給 AI agent、給社群分享 crawler、給 SEO 都讀得懂的個人品牌入口。

我把過去半年自己的 AI 求職工具鏈打包成 SmartResume，今天 release v1.4.2。
一個用 AI Skills 同步維護「portfolio 網站 + 履歷 PDF + 求職應徵流程」的開源工具包。

———

v1.4.2 修了什麼，為什麼值得知道？

把社群分享預覽 pipeline 端到端打通。
過去把連結貼到 LinkedIn / Facebook / Threads，預覽圖會出現空頭像、相對 URL 被 crawler 拒收的狀況 — 都修好了。
SEO / OG meta tags 全部收進 ref_src/main.md 這個 SSOT，fork 完跑一次 /update-resume，網站標題、og:image、twitter description 全部會換成你自己的名字，不會再是 demo 的 Alex Chen。

———

最近三版（v1.4.0 → v1.4.2）做了什麼，跟讀者有什麼關係？

三個全新的SKILL!

1. Case Study 深度頁（v1.4.0）
專案卡片可以升級成完整故事頁，路由 /projects/:id，markdown 撰寫，scaffold 用一行 /add-case-study {projectId}。
解決「履歷沒有故事」的痛點 — 面試官想看你怎麼想，不是只看你做了什麼。

2. /linkedin-suggest 雙語 LinkedIn profile 草稿（v1.4.0）
從 main.md SSOT 一鍵產出 Headline、About、Experience、Skills、Featured、Open to Work。
中英雙語、per-field 互動微調。寫 LinkedIn 不用再自己想兩種版本。

3. /install-avatar + 社群分享預覽修正（v1.4.0 + v1.4.2）
一張原圖 → 自動產 128/256/512 px 多尺寸 WebP+PNG → 同步進履歷 PDF + OG 預覽圖。
fork 完從「demo」變成「自己」，這是最快的一步。

## 撰寫原則 reference

- 開頭兩行決定打開率 — LinkedIn 在 mobile 預設只顯示 ≈ 200 chars，超過要點「see more」才繼續看
- 避免「Excited to announce...」式開頭。直接拋出張力（「履歷不再只是給人看的 PDF」）勝過自我宣告
- 一段一個重點，段落間用視覺分隔線（——— 或空行）斷開，手機掃描友善
- 兩個 demo 連結並列放在中段（≈ 1/2 處），不放結尾 — 多數讀者不會滑到底
- CTA 三選一：避免「全要」，每個讀者自己挑一個落地行動
- 純文字段落，無 markdown `*` / `#` / `-`（LinkedIn 不渲染，貼上會看到原始符號）
- 連結用換行單獨擺放 + 前後加 → 箭頭引導，不要塞在句中
